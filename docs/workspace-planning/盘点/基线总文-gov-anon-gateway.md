## 一、这个系统是什么

gov-anon-gateway 是一个 OpenAI 兼容的政务 AI 安全网关：客户端照常调 `/v1/chat/completions`（流式/非流式），网关在中间完成**识别 → 可逆脱敏 → 敏感度路由（互联网 / 政务云 / 拦截三路）→ 转发 → 客户端侧还原 → 输出防护（AI 生成标识 / 拦截文案 / 代答）→ 审计落库**的全链路。另提供 Word / Excel / PDF / 扫描件的「公开前体检 + 一键导出彻底删除版」文件通道、审计看板与演示前端。规模约 2.6 万行 Python（GLM 记 26292 行 wc -l），README 组件表 12 项 + 仓内未列入组件表的 2 个部署侧件（`gpu/`、`gpu-services/`）。全部安全能力在零真实 API key 依赖下即可运行（mock 上游可全链验收），真实大模型腿经 GPU 隧道 `100.64.0.7:9004`（llm_openai / local-chat-8b）亦可跑通。
